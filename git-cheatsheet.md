# Git Cheat sheet
## Basic commands
### git status
show the current status of the Git repository.

### git add 
Moves changes to the staging area.

### Git commit
save staged changes in Git history

### Git push
uploads local commits to GitHub.

### git pull
Downloads and integrates changes from GitHub

### git log 
show the commit history of the repository

### git branch
Lists existing branches and helps manage branches.

### git checkout 
switches between branches or restores files depending on usage.
